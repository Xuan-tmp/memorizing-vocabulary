# 单词抽背

Windows 桌面应用，使用系统自带 .NET Framework，离线运行。

运行 `build.ps1` 编译，启动 `dist\单词抽背.exe`。数据存于程序旁 `data\vocabulary.xml`，请将程序放在可写目录。

批量导入每行格式：`pulse | 25 | n.: 脉搏 | v.: 搏动，跳动；洋溢着`。分号分隔独立意思，逗号保留在同一个意思内。导入先预览检查，重复单词跳过。

答题按回车提交，答对或三次错误后按回车进入下一题。使用提示、答错或跳过都属于不熟练。每轮结果可以继续加深记忆；保留最近五轮记录（包括强化轮）。

数据菜单可备份、恢复。恢复会覆盖当前数据。安装包脚本 `installer.iss` 可使用 Inno Setup 编译；默认安装在当前用户可写目录。
